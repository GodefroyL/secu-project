HDR-0007 Medium OWASP A03

Cookie 'SOCS' missing HttpOnly flag

Asset: https://google.com

Source: headers_probe (custom_probe)

Preuves Techniques

Set-Cookie: SOCS=CAAaBgiAoqvLBg; expires=Tue, 16-Feb-2027 13:04:09 GMT; path=/; domain=.google.com; Secure; SameSite=lax
Without HttpOnly, JavaScript can access this cookie (XSS risk).

Recommandations

  • Add the HttpOnly flag to prevent JavaScript access
  • Example: Set-Cookie: name=value; HttpOnly
  • This is critical for session cookies
HDR-0008 Medium OWASP A01

Cookie '__Secure-BUCKET' missing SameSite attribute

Asset: https://google.com

Source: headers_probe (custom_probe)

Preuves Techniques

Set-Cookie: __Secure-BUCKET=CMQF; expires=Thu, 16-Jul-2026 13:04:09 GMT; path=/; domain=.google.com; Secure; HttpOnly
Without SameSite, cookie is vulnerable to CSRF attacks.

Recommandations

  • Add SameSite=Strict or SameSite=Lax
  • SameSite=Strict provides maximum CSRF protection
  • SameSite=Lax is a reasonable default
